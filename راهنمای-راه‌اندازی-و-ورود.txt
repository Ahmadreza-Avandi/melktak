راهنمای راه‌اندازی Amlak OS و ورود به پنل‌ها
============================================

۱) اجرای پروژه
-------------
در پوشه اصلی پروژه، ترمینال را باز کنید و اجرا کنید:

  npm install
  npm run dev

برنامه به‌صورت پیش‌فرض روی این نشانی در دسترس است:

  http://localhost:3000

برای بررسی سلامت API این نشانی را باز کنید:

  http://localhost:3000/api/v1/health

در پاسخ سالم، مقدار database.status باید connected باشد.


۲) ورود مدیر کل پلتفرم
---------------------
از صفحه اصلی روی «ورود مدیر کل پلتفرم» بزنید یا مستقیماً وارد این نشانی شوید:

  http://localhost:3000/platform/login

اطلاعات حساب مدیر کلِ دیتابیس محلی فعلی:

  نام کاربری: admin_root
  6wly4TeL0vqT2-_gtyb-xJEGJMb1ZaWv

مدیر کل در سطح پلتفرم فعالیت می‌کند و از ورود عادی آژانس جداست. بعد از ورود،
از بخش مدیریت آژانس‌ها می‌توانید دفتر املاک جدید بسازید. هنگام ساخت آژانس،
کد آژانس و مشخصات مدیر آن را ثبت کنید؛ برای ورود بعدی آن مدیر، کد آژانس،
نام کاربری و رمزی که تعیین کرده‌اید لازم است.


۳) ورود به آژانس نمونه
---------------------
فرم ورود عادی در صفحه اصلی برای ورود کاربران یک آژانس است. اطلاعات نمونه:

  کد آژانس: DEMO01
  نام کاربری: agent
  رمز عبور: DemoPassword123!

حساب‌های نمونه admin، manager و ahmadreza نیز در دیتابیس فعلی با همین رمز
نمونه ساخته شده‌اند. حساب ahmadreza مدیر آژانس است، نه مدیر کل پلتفرم.


۴) ساخت مدیر کل برای دیتابیس جدید
--------------------------------
برای هر نصب تازه، یک رمز دلخواه و قوی تعیین کنید و در پوشه اصلی پروژه اجرا
کنید:

  npx tsx scripts/provision-platform-admin.ts <نام‌کاربری> <رمز>

برای نمونه:

  npx tsx scripts/provision-platform-admin.ts admin_root رمز-قوی-خودتان

این دستور حساب مدیر کل را می‌سازد یا رمز حسابی با همان نام کاربری را تغییر
می‌دهد. حساب مدیر کل فعلی این دیتابیس با راه‌اندازی مجدد برنامه بازنشانی
نمی‌شود.


۵) نکات عیب‌یابی
----------------
- اگر صفحه باز نمی‌شود، مطمئن شوید دستور npm run dev هنوز در ترمینال در حال اجراست.
- اگر ورود آژانس ناموفق است، کد آژانس، نام کاربری و رمز را جداگانه بررسی کنید.
- مدیر کل از مسیر /platform/login وارد می‌شود؛ او را از فرم ورود عادی آژانس
  وارد نکنید.
- داده‌های محلی دیتابیس در مسیر data/amlak_postgres نگهداری می‌شوند. این پوشه
  را برای پاک‌سازی پروژه حذف نکنید؛ حذف آن می‌تواند داده‌های محلی را از بین ببرد.
- رمزهای این فایل فقط برای دیتابیس محلی فعلی هستند. فایل را در مخزن عمومی،
  سایت یا کانال عمومی منتشر نکنید. در صورت اشتراک‌گذاری فایل، ابتدا رمز مدیر کل
  را با دستور provisioning بالا عوض کنید.
